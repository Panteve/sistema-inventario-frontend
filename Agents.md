# AGENTS.md

## Objetivo

Antes de realizar cualquier tarea, revisar si existe una skill o guía especializada que aplique al trabajo solicitado.

## Flujo de trabajo

1. Analizar la solicitud del usuario.
2. Revisar la carpeta `.skills/` (esta oculta).
3. Identificar las skills relevantes para la tarea.
4. Leer completamente las skills seleccionadas antes de generar una respuesta o modificar código.
5. Aplicar las reglas y recomendaciones encontradas.
6. Si varias skills aplican, combinar sus instrucciones de forma coherente.
7. Si ninguna skill aplica, continuar utilizando buenas prácticas generales.

## Priorización

En caso de conflicto entre instrucciones:

1. Requisitos explícitos del usuario.
2. Reglas del proyecto.
3. Skills especializadas.
4. Buenas prácticas generales.

## Generación de código

Antes de crear o modificar código:

* Revisar si existe una skill relacionada con el lenguaje o framework utilizado.
* Mantener consistencia con el código existente.
* Evitar introducir patrones diferentes a los definidos por las skills.
* Explicar decisiones importantes cuando sea necesario.

## Testing y calidad

Cuando exista una skill de testing, accesibilidad, seguridad o revisión de código, aplicarla automáticamente si es relevante para la tarea.
